Chmod Permissions Calculator

Unix permissions are three trios of read (4), write (2) and execute (1) — add within each trio for the octal digit. Pick each group's access for the number, the symbolic string, and what each class can actually do.

Each digit = read (4) + write (2) + execute (1), for owner, group, others

Worked example

Worked example: owner rwx (7), group r-x (5), others r-x (5) → chmod 755, written −rwxr-xr-x — the standard for web directories and scripts.

How to play Sudoku Mini

Fill the 4x4 grid so every row, column and box has 1, 2, 3 and 4.

  1. Tap an empty square, then tap a number to place it.
  2. A number can appear only once in each row, column and box.
  3. Use the given numbers as clues and work out the rest.

Baluster Spacing Calculator

Building codes limit the gaps in a guardrail so a 4-inch sphere cannot pass through — the size of a small child's head. Given your railing run and baluster width, this finds the fewest balusters that satisfy the rule, then works out the exact even spacing to mark on the rail.

Balusters needed = the smallest n with (run − n × width) ÷ (n + 1) ≤ max gap · Actual gap = (run − n × width) ÷ (n + 1)

Worked example

Worked example: a 96-inch run with 1.5-inch balusters and a 4-inch maximum gap → 17 balusters, leaving 18 gaps of exactly 3.92 inches. Centre-to-centre spacing is 5.42 inches — the number to mark along the tape.

Card Number Checker (Luhn)

Every genuine card number satisfies the Luhn algorithm: double every second digit, sum everything, and the total must end in zero. It catches typos, not fraud — and it runs entirely on this page, so test numbers never travel anywhere.

From the right: double every second digit (subtract 9 if the double exceeds 9), sum all digits — valid when the sum mod 10 = 0

Worked example

The payment industry's standard test number 4242 4242 4242 4242 passes Luhn (that is its purpose). Change the final 2 to a 3 and it fails instantly.

NFL Passer Rating Calculator

The NFL's passer rating squashes completion %, yards per attempt, touchdown rate and interception rate into one number capped at 158.3. This tool shows all four components — so you can see which one is dragging (or carrying) the rating.

Each of the four rates is scaled and clamped to 0–2.375, then: rating = (a + b + c + d) ÷ 6 × 100

Worked example

Worked example: 325/500 completions, 3,800 yards, 28 TD, 10 INT → components 1.750 + 1.150 + 1.120 + 1.875 → rating 98.3 — a strong Pro Bowl-level season.

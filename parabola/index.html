Parabola Calculator

Every quadratic is a parabola with a turning point (the vertex), a focal point that defines its curve, and up to two crossings of the x-axis. Enter a, b and c and this maps all of it — the same numbers you would read off a careful graph, without drawing one.

Vertex x = −b ÷ 2a · Discriminant = b² − 4ac · Roots = (−b ± √discriminant) ÷ 2a · Focus offset = 1 ÷ 4a from the vertex

Worked example

Worked example: y = x² − 4x + 3 → vertex (2, −1), roots x = 1 and x = 3, axis x = 2, focus (2, −0.75), directrix y = −1.25, opening upward.

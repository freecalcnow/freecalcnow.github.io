Sortino Ratio Calculator

The Sharpe ratio punishes upside surprises as 'risk', which investors rarely mind. The Sortino ratio divides the average return by downside deviation only — the spread of returns below your target — so strategies that wobble upward are not penalised for it.

Sortino = (mean return − target) ÷ downside deviation, where downside deviation uses only returns below target

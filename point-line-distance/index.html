Point to Line Distance Calculator

The shortest route from a point to a line is always the perpendicular. This computes that distance for a line written as Ax + By + C = 0, and also finds the foot — the exact point on the line where the perpendicular lands.

Distance = |A x₀ + B y₀ + C| ÷ √(A² + B²)

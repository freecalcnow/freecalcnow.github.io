Logarithm Calculator

A logarithm answers “what power gives me this number?” — the inverse of exponentiation. Enter a value and a base; log base 10, base e (ln) and base 2 are shown too, because different fields swear by different bases.

log_b(x) = ln(x) ÷ ln(b) · log₁₀, ln and log₂ shown for every input

Worked example

Worked example: log₁₀(1000) = 3, because 10³ = 1000. log₂(1024) = 10, because 2¹⁰ = 1024 — the reason a kilobyte is 1024 bytes, not 1000.

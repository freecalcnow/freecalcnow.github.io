Codon Table & DNA Translation Tool

Three letters at a time, the ribosome reads the genetic code: 64 codons, 20 amino acids, one start and three stops. Paste a coding sequence (DNA with T, or mRNA with U) and this tool translates it in frame, marking the start codon and every stop.

Translation reads codons (triplets) from the first base · ATG/AUG = Methionine = START · TAA, TAG, TGA (UAA, UAG, UGA in RNA) = STOP · The standard genetic code is used

Worked example

Worked example: ATG GCT TTT TAA translates to Met–Ala–Phe–STOP — a complete tiny message: start, two building blocks, full stop. Real genes run from a few hundred to tens of thousands of codons.

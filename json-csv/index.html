JSON ↔ CSV Converter

The two formats every dataset shuttles between. Paste a JSON array of flat objects to get CSV with a header row, or paste CSV to get a JSON array back. Values containing commas or quotes are escaped properly in the CSV direction; the reverse assumes simple, unquoted CSV.

JSON → CSV: header = the keys, one object per row, RFC-4180 quoting · CSV → JSON: first row = keys, rest = objects

Worked example

Worked example: [{name: Ada, age: 36}, {name: Alan, age: 41}] becomes the CSV 'name,age / Ada,36 / Alan,41' — and that CSV converts straight back to the same JSON.

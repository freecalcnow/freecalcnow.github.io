Ramp Slope & Gradient Calculator

Ramp steepness is stated three ways — ratio (1:12), percent (8.33%) and angle (4.76°) — and they are all the same number. Enter rise and run for all three, plus the verdict against common accessibility guidance.

Gradient % = rise ÷ run × 100 · Ratio = 1 : (run ÷ rise) · Angle = arctan(rise ÷ run)

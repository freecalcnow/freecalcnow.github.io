Number Base Converter

Computers count in binary and abbreviate in hex; humans count in decimal. Enter a whole number in any of the four bases and get the other three — with the digit check that catches a stray “2” in a binary number.

Each base counts in powers of its radix: binary 2, octal 8, decimal 10, hexadecimal 16 (digits 0–9 then A–F)

Worked example

Worked example: FF in hexadecimal = 255 in decimal = 11111111 in binary = 377 in octal. The decimal number 2026 is 7EA in hex.

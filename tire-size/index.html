Tyre Size Calculator

A tyre code like 225/65R17 is width in mm, sidewall as a percentage of width, and rim diameter in inches. This decodes one size fully, then compares a second size against it — including the speedometer error the swap creates, the number that actually matters.

Diameter = rim (in) + 2 × (width × aspect% ÷ 2540) inches · Speedo error follows the diameter ratio

Worked example

Worked example: 225/65R17 → sidewall 146 mm, overall diameter 724 mm (28.5 in), circumference 2,275 mm, about 440 revolutions per km.

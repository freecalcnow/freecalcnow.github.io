Sensitivity & Specificity Calculator

Every test — medical, quality control, spam filter — makes four kinds of result: true positives, false positives, true negatives, false negatives. From those four counts come the five numbers that describe how much a result can be trusted.

Sensitivity = TP ÷ (TP + FN) · Specificity = TN ÷ (TN + FP) · PPV = TP ÷ (TP + FP) · NPV = TN ÷ (TN + FN)

Worked example

Worked example: TP 90, FN 10, FP 20, TN 880 → sensitivity 90%, specificity 97.8%, but PPV only 81.8% — because the condition is uncommon, most positives still deserve a second look.

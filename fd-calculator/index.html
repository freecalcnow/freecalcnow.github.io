FD / Fixed Deposit Calculator

A fixed deposit pays a set rate for a set term. The compounding frequency is the only subtlety: quarterly compounding (the Indian bank standard) beats yearly by a visible margin on long terms.

Maturity = principal × (1 + rate ÷ n)^(n × years), n = compounds per year

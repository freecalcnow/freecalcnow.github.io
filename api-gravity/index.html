API Gravity Calculator

Petroleum is graded on an inverted density scale: the lighter the oil, the higher its API gravity — and the higher its price, because light crude yields more petrol and diesel. Water sits at exactly 10°; anything below sinks in it. Convert both ways, with density in kg/m³ alongside.

API = 141.5 ÷ specific gravity − 131.5 · SG = 141.5 ÷ (API + 131.5)

Worked example

Worked example: a crude with specific gravity 0.85 → API = 141.5 ÷ 0.85 − 131.5 ≈ 34.9° — a medium-light crude. Brent trades around 38°, WTI around 40°.

Download / Transfer Time Calculator

File sizes are counted in bytes and connection speeds in bits — a factor of eight apart, which is why a '100 megabit' line downloads at about 12.5 megabytes a second. This tool keeps the two straight and gives you the honest wait time.

Time = file size (in bits) ÷ speed (bits per second) · 1 byte = 8 bits · This tool uses decimal units (1 GB = 1,000 MB), as ISPs and drive makers do

Worked example: a 10 GB game update on a 100 Mbps line takes 800 seconds — 13 minutes 20 seconds — in perfect conditions. Real lines run slower; the rows show 70% efficiency too.

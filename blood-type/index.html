Blood Type Inheritance Calculator

ABO blood type is inherited as two alleles — one from each parent — where A and B are both dominant over O. Enter each parent's genotype (type A can be AA or AO; the calculator needs the alleles, not just the letter on the card) and see every child outcome with its probability.

Each parent passes one allele at random · AA/AO → type A · BB/BO → type B · AB → type AB · OO → type O

Worked example

Worked example: an AO parent and a BO parent can have a child of any type — AB, A, B or O at exactly 25% each. That is why an O child can surprise two non-O parents.

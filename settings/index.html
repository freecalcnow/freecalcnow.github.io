Your Gemini API key

Paste your own free Gemini API key to let the Ask FreeCalcNow assistant answer with AI. The key is saved only in this browser (on this device) and is sent only to Google's Gemini API — never to us, never to any other server. Your questions go to Google too, only when you ask. Without a key, the assistant still works offline with its built-in calculator help.

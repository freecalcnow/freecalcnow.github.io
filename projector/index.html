Projector Throw Distance Calculator

A projector's throw ratio says how far back it must sit for every unit of screen width: distance = screen width × ratio. Enter the screen's diagonal (16:9) and the lens's ratio range from the spec sheet, and get the mounting distance window.

Screen width = diagonal × 0.8716 (16:9) · Throw distance = screen width × throw ratio

Worked example

Worked example: a 100-inch screen is 87.2 in wide. A lens rated 1.5–1.8 throws it from 10.9 ft (at 1.5) to 13.1 ft (at 1.8).

Exposure Value (EV) Calculator

Exposure value compresses the three exposure settings into one number matched to the light itself: bright sun is EV 15, a living room about EV 6. Photographers swap settings freely along one EV line — this computes yours and names the light it belongs to.

EV (at ISO 100) = log₂(aperture² ÷ shutter time in seconds) · Adjust for ISO: EV = EV₁₀₀ + log₂(ISO ÷ 100) when solving for scene brightness

Worked example

Worked example: f/8 at 1/250 s and ISO 100 → log₂(64 × 250) = log₂(16,000) ≈ EV 14 — bright daylight, one stop off full sun. The old 'Sunny 16' rule is exactly EV 15.

Image File Size Estimator

File size is pixels × how hard the format works. Uncompressed formats are exact; compressed ones (JPEG, WebP) vary with the picture's detail — this uses typical photographic averages and labels them as estimates.

Megapixels = width × height ÷ 1,000,000 · Size ≈ pixels × bytes-per-pixel for the format

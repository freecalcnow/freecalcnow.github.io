String Vibration Calculator

A stretched string's fundamental note rises with tension, falls with length, and falls with mass per metre — Mersenne worked out the exact law in 1637, and every stringed instrument is built on it. This also gives the wave speed on the string and the first harmonics.

f = (1 ÷ 2L) × √(T ÷ μ), where μ = mass per unit length

Worked example

Worked example: a 0.65 m guitar string under 70 N with μ = 1 g/m → wave speed 265 m/s, fundamental ≈ 204 Hz — close to G♯3; a touch more tension reaches A.

RNA Transcription & Complement Tool

Three transformations run molecular biology's daily errands: transcription (coding DNA to mRNA — same sequence, U for T), the complementary strand (A↔T, G↔C), and the reverse complement, which is how the other strand reads in the standard 5′→3′ direction.

Transcription: copy the coding strand, replacing T with U · Complement: A↔T, G↔C · Reverse complement: complement, then reverse the order

Worked example

Worked example: the coding sequence ATGGCTTAA transcribes to the mRNA AUGGCUUAA — a start codon (AUG), an alanine (GCU) and a stop (UAA).

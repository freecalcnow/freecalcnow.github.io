CSS Units Converter (px ↔ rem ↔ em)

CSS sizes come in absolute pixels and relative rem/em — and converting between them is constant friction. This tool converts all of them against your root font size, and shows the common sizes table designers actually use.

rem = px ÷ root font size (16 px by default) · em equals rem when the parent is the root · pt = px × 0.75

Worked example

Worked example: at the default 16 px root, 24 px = 1.5 rem; 0.875 rem = 14 px — the standard small-text size.

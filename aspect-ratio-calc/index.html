Aspect Ratio Calculator

Is 2560×1440 really 16:9? What height keeps 16:9 at 1,920 wide? This simplifies any width:height pair to its true ratio and resizes without distortion.

Ratio = width ÷ GCD : height ÷ GCD · New height = new width × (height ÷ width)

Delay Time Calculator

Set a delay pedal by ear no more: the echo time for any note value is fixed by the tempo. Quarter note = 60,000 ÷ BPM milliseconds; every other value scales from there. The dotted-eighth setting — three quarters of a beat — is the famous one for rhythmic, galloping echoes.

Quarter note (ms) = 60,000 ÷ BPM · Whole = ×4 · Half = ×2 · Quarter = ×1 · Eighth = ÷2 · Sixteenth = ÷4 · Dotted = ×1.5 · Triplet = ×⅔

Worked example: at 120 BPM a quarter note is 500 ms, an eighth 250 ms, a dotted eighth 375 ms and an eighth triplet about 167 ms.

Electron Configuration Finder

Electrons fill orbitals in a fixed order (the Aufbau principle): 1s, 2s, 2p, 3s, 3p, 4s, 3d… Enter an atomic number and this writes the full configuration, the noble-gas shorthand, and how many electrons sit in each shell — with chromium and copper's real-world exceptions honoured.

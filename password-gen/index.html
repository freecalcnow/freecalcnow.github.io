Password Generator & Strength Checker

Random passwords generated with the Web Crypto API — the same cryptographic randomness your browser uses for secure connections — with a live strength meter built in, so you can see the entropy of every password the moment it is made. Nothing is sent anywhere; close the tab and the password is gone unless you saved it.

Entropy = length × log₂(character pool size). A 16-character password from a 72-character pool carries ≈ 98.7 bits of entropy.

Worked example

Worked example: a 12-character password using upper, lower, digits and symbols draws from about 94 characters — roughly 79 bits of entropy, or about 4.8 × 10²³ combinations. Length beats cleverness: four random words beat one short “clever” password.

Frequently asked questions

What length should I use?

16 or more characters for anything important, with a unique password per account — a password manager makes that painless. The generator’s default of 16 is a good floor.

Why not just use a memorable password?

Because humans are predictable: names, dates, keyboard patterns and “clever” substitutions are all in cracking dictionaries. Genuine randomness is the whole defence.

Is it safe that this runs in a web page?

Generation happens entirely on your device using crypto.getRandomValues. No server sees it — you can verify by loading the page and switching off your network: it still works.
